# PowerBI_Hospitality_Dashboard
Hospitality_Domain_Revenue_Analysis

This project features a Revenue Insights Dashboard for ATLiq, built using Microsoft Excel and Power BI, designed to track and analyze key hospitality metrics across properties and booking platforms to maximize revenue.

📊 Dashboard Features

Dynamic Filters: Filter data by City, Room Class, and Price Level Change for customized insights
Revenue Overview: Displays key performance metrics such as Revenue, RevPAR, ADR, Occupancy, and Realisation %
DSRN Analysis: Tracks Daily Saleable Room Nights across properties
Revenue by Category: Breaks down revenue by Business, Category, and Luxury segments
Time Trend Analysis: Visualizes weekly trends for Occupancy, ADR, and Realisation
Property Performance: Compares properties across metrics like Total Bookings, Cancellation %, and Average Rating
Platform Analysis: Analyzes Realisation % and ADR across various booking platforms

🔧 Tools Used

Microsoft Excel: Used for initial data preparation, cleaning, and sourcing.

Power BI: Used for data modeling, DAX calculations, and creating interactive visualizations.
